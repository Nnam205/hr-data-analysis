# HR Data Analysis

## Mục tiêu
Phân tích dữ liệu nhân sự để giúp công ty hiểu rõ 
tình trạng nhân viên và đưa ra quyết định quản lý tốt hơn.

## Dataset
- 2,845 nhân viên
- 28 cột dữ liệu
- Thông tin: phòng ban, performance, training, engagement

## Công cụ
- SQL — truy vấn và xử lý dữ liệu
- Python — phân tích và mô hình dự đoán  
- Power BI — dashboard và báo cáo

## Cấu trúc project
- data/ — dataset gốc
- sql/ — các câu truy vấn SQL
- python/ — notebook phân tích
- powerbi/ — file dashboard
